Build a modern, responsive web application called WISE WIRAZAD   Assistant that helps with your rights in the workplace with security hazards easily accessible navigating system, with my business slogan written in bold with color green that is "We fight for your rights your voice is heard" automate workplace tasks using AI.

The application should include:

Smart Email Generator

AI Task Planner 

AI Research Assistant

AI Chatbot Interface

Requirements:

Modern dashboard UI

Sidebar navigation

Responsive design

Structured AI prompts

Editable AI outputs

Responsible AI disclaimer

Design style should be clean, modern, and professional similar to a SaaS platform.
